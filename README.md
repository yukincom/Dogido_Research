# Dogido Research

ドギドの川柳と、その制作記録を読む公開の本棚です。本体と同じインターフェイスで、原句・推敲履歴・川柳の相談・発句材料・写真を閲覧できます。

- [本棚をひらく](https://yukincom.github.io/Dogido_Research/)
- [ドギドを試す・本体の導入方法](https://github.com/yukincom/DokiDoki_Dogido#readme)
- [公開データ（JSON）](site/data/research.json)

普段の対話・個人メモ・端末内のパス・生の個体IDは公開データへ含めません。川柳相談は元記録との照合を通った、実際に届けられた対話だけです。内部状態の数値データはまだ収録していません。

更新手順と公開範囲は [公開データの作り方](docs/2026-10-24-publication.md) を参照してください。GitHub Actionsが検証後に `site/` をGitHub Pagesへ公開します。
